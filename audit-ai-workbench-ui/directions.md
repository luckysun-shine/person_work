# 六个候选方向

## 候选一 证据账本

- 逻辑与来源：Edward Tufte 的数据墨水与小倍图思维。
- 借的是什么：减少容器装饰，用细规则线、紧凑表格和内联趋势表达信息关系；正文与数据共享清晰基线。
- 主角素材：数据本身，包括 SQL 复用次数、任务流转和模型运行的微型趋势。
- 骨架：窄左栏加宽主区，首页像一张可操作的分析记录页。
- 胆量花在哪：取消大部分卡片，让连续数据和注释直接构成页面。
- form 来自内容的哪里：审计判断依赖证据链，版式也用连续证据而不是装饰容器组织。

## 候选二 无声档案

- 逻辑与来源：原研哉的信息减法和东亚留白逻辑。
- 借的是什么：宽留白、低饱和背景、极少强调色、标题与正文之间的大尺度节奏。
- 主角素材：项目与模型的文字记录，配合一枚朱色状态印记。
- 骨架：细窄目录与单列主内容，详情像被整理过的个人档案。
- 胆量花在哪：信息密集产品仍保留大面积呼吸区。
- form 来自内容的哪里：个人工作台需要长时间阅读，安静感来自减少同时争夺注意力的元素。

## 候选三 企业操作网格

- 逻辑与来源：IBM Carbon 数据表与企业工具规范。
- 借的是什么：16 列网格、全宽数据表、工具栏与行高对应、排序筛选和展开行形成一致操作语言。
- 主角素材：可扫描的数据表、状态标记和结构化筛选器。
- 骨架：固定侧栏、上下工具栏、全宽主表与右侧详情抽屉。
- 胆量花在哪：采用高密度但严格对齐的操作界面，不靠大卡片缓冲。
- form 来自内容的哪里：SQL 和模型资产天然是可筛选、可排序、可追溯的资源集合。

## 候选四 SQL 工作室

- 逻辑与来源：Supabase Dashboard SQL Editor。
- 借的是什么：项目壳与代码工作区的明确分层、编辑器占据视觉中心、保存查询与数据库对象保持近距离。
- 主角素材：真实结构的 SQL 代码、参数和对象关系。
- 骨架：左侧对象树、中部代码、右侧元数据，首页则收敛为运行与工作摘要。
- 胆量花在哪：把代码阅读区提升为产品核心，而不是塞进普通详情卡片。
- form 来自内容的哪里：用户最难复用的资产是 SQL 逻辑，因此代码必须获得最大阅读空间。

## 候选五 执行脉冲

- 逻辑与来源：秒数轮盘 Web 08 电影感声波可视化。
- 借的是什么：纯黑背景、单一电蓝强调、贯穿页面的波形和高对比标题。
- 主角素材：将模型运行批次与 SQL 执行时间转换成脉冲轨迹。
- 骨架：暗场全幅运行轨迹加底部功能区。
- 胆量花在哪：模型运行轨迹成为首页主视觉。
- form 来自内容的哪里：监测模型按照批次持续运行，时间序列可以自然形成脉冲，而不是借用声音作为装饰。

## 候选六 摩登台账

- 逻辑与来源：秒数轮盘 East 04 上海摩登装饰艺术。
- 借的是什么：墨绿、金和朱红三色，对称几何、双框和日历式时间组织。
- 主角素材：本周工作日历和结构化台账。
- 骨架：对称门框式首页，周计划像月份牌日历，详情回到规整两栏。
- 胆量花在哪：把本周计划做成强识别度的时间门面。
- form 来自内容的哪里：周计划和定期监测都与日历强相关，月份牌的时间结构可以被重新解释。

## 完整版选择

根据单看质量、彼此差异、专业场景适配和避免用力过头四项标准，完整版选择如下：

1. 证据账本，代表克制的数据叙事方向。
2. 企业操作网格，代表高密度的业务系统方向。
3. SQL 工作室，代表技术资产优先的深色工作环境。

执行脉冲和摩登台账保留在缩略图中作为大胆备选，无声档案保留为安静备选。
