# 方向候选 · Crextio 软 UI 语境（数智审监工作台）

用户指定参考：`design-demos/ref-crextio.jpg`。六个候选都在「暖浅底 + 大圆角白卡 + 金黄强调 + 炭黑焦点」语境内，差异落在**骨架与信息组织**，不在换皮配色。

秒数轮盘：S=51 → web `51%20+1=12` 暖色编辑风；east `51%12+1=4` 海派月份牌。在 Crextio 语境内兼容诠释，不滑向赤陶衬线默认皮。

---

## 六候选卡

### C1 · 最佳设计师｜软欢迎便当台 Soft Welcome Bento
- **逻辑与来源**：把 Crextio 首屏逻辑直接迁到审计工作台（欢迎语 + 进度条 + 右侧大数字 + 中部 widget + 下部三栏）。
- **借的是什么**：顶栏居中胶囊导航；页面径向浅黄底；卡片 28px 圆角轻阴影；金黄进度；右下炭黑任务卡。
- **主角素材**：程序化进度环 / 柱 + 真实业务文案（无真人肖像，改用项目焦点卡）。
- **骨架**：顶导航 → 欢迎横幅 → 2×2 中部组件 → 下部请求 / 日程 / 今日任务。
- **胆量花在哪**：欢迎区大标题「早上好，审计员」压住整屏气质。
- **form**：审计师每天先「定向」再干活，欢迎区就是定向。

### C2 · 最佳设计师｜软侧栏作战台 Soft Rail Desk
- **逻辑与来源**：同一软材质，但用左侧浮起软侧栏承载高频模块（适合信息密度更高的 SQL / 请求流）。
- **借的是什么**：Crextio 的圆角、金黄、炭黑；骨架改为左轨 + 右主区，顶栏只留搜索与设置。
- **主角素材**：左侧模块胶囊 + 右侧任务/请求双列。
- **骨架**：左软轨（今日/请求/SQL/模型/项目）→ 右欢迎条精简 → 主内容双栏。
- **胆量花在哪**：侧栏本身是一张大圆角白卡浮在黄底上。
- **form**：审计工具切换频繁，侧栏比八项顶导航更稳。

### C3 · 现实参照｜Crextio 原图直译工作台
- **逻辑与来源**：用户参考图 `ref-crextio.jpg`（已亲眼看）。
- **借的是什么**：欢迎区进度点列、人物卡改为「当前焦点项目」大卡、工时柱图改为「本周完成」、圆形计时改为「等待他人」、底部手风琴改为「关联资产」、中间周日程、右侧炭黑 Onboarding Task → 今日待办。
- **主角素材**：参考图结构 1:1 映射业务模块。
- **骨架**：与 C1 接近，但中部第一卡是项目焦点大卡而非人像。
- **胆量花在哪**：中部左侧超大项目焦点卡。
- **form**：审计日常围着「一个重点项目」转。

### C4 · 现实参照｜Glassmorphism Bento × 暖黄
- **逻辑与来源**：风格库 web/13 glassmorphism-bento，降饱和蓝紫为暖金，底改为浅暖而非近黑。
- **借的是什么**：更强的 bento 分块、发丝分割、半透明叠层；仍用 Crextio 暖色。
- **主角素材**：半透明玻璃卡叠在渐变底上。
- **骨架**：顶 pill + 不规则 bento（跨行跨列）+ 底部通栏 SQL 预览条。
- **胆量花在哪**：一块跨两列的 SQL 只读预览作为首页视觉锚。
- **form**：SQL 是这个工作台独有的「正文」。

### C5 · 秒数轮盘｜web#12 暖编辑 × Crextio 材质
- **逻辑与来源**：抽到 warm-editorial；在 Crextio 语境里只用其「标题层级与阅读节奏」，不用赤陶衬线纸感全家桶。
- **借的是什么**：更大的标题字阶、段落式说明、节制分割；材质仍是黄底白卡金黄点。
- **主角素材**：大标题 + 短说明段落主导首页。
- **骨架**：顶导航 → 编辑式欢迎（标题+一段话）→ 三列内容流（非严格 bento）。
- **胆量花在哪**：首页先读一段「今日判断」，再进列表。
- **form**：审计工作需要先判断再执行。

### C6 · 秒数轮盘｜east#4 海派月份牌节奏 × 软 UI
- **逻辑与来源**：上海月份牌的「月历主导 + 装饰分区」；材质改成 Crextio 软卡。
- **借的是什么**：周/日计划作为视觉中轴，左右辅以任务与请求。
- **主角素材**：横向周日程大卡居中。
- **骨架**：顶导航 → 精简欢迎 → **中央周日程通栏** → 左右任务/请求。
- **胆量花在哪**：日程占首页一半高度。
- **form**：周计划是审计个人台的时间骨架。
