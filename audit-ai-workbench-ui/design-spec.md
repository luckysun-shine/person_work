# 设计探索规范 · Crextio 软 UI 改版

## 本质需求

这是给审计监察数据分析师每天长时间使用的个人工作台「数智审监工作台」。需要把今日任务、数据请求、SQL 复用、监测模型与项目推进放进同一操作环境。本轮按用户提供的 Crextio 风格参考图重做整体视觉：暖黄浅底、大圆角白卡片、胶囊导航、金黄进度强调、炭黑焦点面。

## 参考资产

- 用户参考图：`design-demos/ref-crextio.jpg`
- 借的规则：页面级浅暖渐变底；白卡片圆角约 24–30px + 轻阴影；居中或对称的胶囊导航（黑底激活）；金黄 `#F5C84B` 系进度与完成态；炭黑 `#1C1C1C` 用于主按钮与重点任务卡；细线图标；欢迎区大标题 + 右侧大数字；中部 bento 小组件；下部列表 / 日程 / 任务并列。

## 受众与场景

- 受众：熟悉 SQL、数据分析与审计业务的单人专业用户。
- 场景：桌面一米视距长时间使用；偶尔手机快速看任务。
- 高频：找回 SQL、处理数据请求、看模型状态、安排本周工作。

## 共同内容（三方向必须一致）

### 首页工作台

- 今日待办 5、本周完成 12、等待他人 3。
- 重点项目：采购异常监测模型、审计报告数据支撑、制度知识库。
- 最近数据请求：固定资产盘点差异、采购付款明细、供应商关联分析。
- 常用入口：审计系统、数据仓库、BI 平台、法规库、知识库。

### 数据请求 / SQL / 模型

- 请求可关联并跳转 SQL 与项目。
- SQL 列表：名称、用途、涉及表、项目、版本、更新、复用次数；详情含语法高亮（只读不执行）。
- 模型：规则、版本、运行状态、频率、依赖、更新步骤。

## 输出范围（本回合）

- 六候选缩略图总览一份（画布宽 1440）。
- 三个完整单文件 HTML，各含四个可切换代表页：今日 / 请求 / SQL / 模型。
- 当前回合只交付方向稿，**不改生产代码**；用户选定后再落地 `workbench-v2`。

## 共同约束

- 中文正文 ≥14px，主要正文 15–17px；可点区 ≥44×44；对比度 ≥4.5:1。
- 数字用等宽特性。
- 不使用紫色全屏渐变、Emoji 导航、虚构评价。
- 三方向都在 Crextio 软 UI 语境内，但骨架必须彼此不同。

## 五问答案

- 叙事角色：每日开工定向台，不是展示大屏。
- 观众距离：桌面信息密度优先。
- 视觉温度：温暖、柔软、可信；允许一处炭黑对比，不娱乐化。
- 容量：首页同时容纳任务、项目、请求；列表每屏 ≥6 条。
- 视觉母题：可追溯链条（请求 → SQL → 项目 / 模型），用软卡片与跳转链表达。
