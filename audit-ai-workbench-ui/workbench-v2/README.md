# 审计 AI 个人工作台 V2（v1.9.0）

这是一个面向审计监察数据分析师的本地单用户工作台，围绕以下工作闭环组织：

`工作请求 → 周计划 → SQL 取数 → 模型维护 → 项目推进 → 记录复盘 → 周报输出`

## 当前内容

- 12 个工作区：今日、本周计划、报告助手、数据请求、统一检索、SQL 资产、存储过程、监测模型、项目与报告、工作记录、常用导航、数据管理。
- 可用交互：页面导航、任务完成、周次切换、模型页签与检查步骤、全局搜索和快速记录。
- 数据请求：新增、编辑、删除、搜索、批量完成和批量删除；支持需求人/部门、等待对象、交付方式与位置、敏感说明。
- SQL 资产：新增、编辑、删除、搜索、详情抽屉、复制 SQL、批量验证和批量删除；支持独立版本历史、版本对比（diff）与敏感信息检查。
- 监测模型：支持新增、编辑、删除，维护规则、依赖、关联 SQL、版本历史和可勾选的更新步骤，并记录每次运行结果。
- 项目与报告：支持新增、编辑、归档、删除，并统一维护项目与 SQL、模型、任务、数据请求及工作记录的关联关系。
- 工作记录：新增、编辑、删除、标签与关联对象、批量删除，以及按真实数据生成的分类数量、分类筛选和全文搜索。
- 常用导航：支持分组展示、搜索、新增、编辑、删除、真实地址访问、访问次数和最近使用时间记录。
- 存储过程：支持资产新增、编辑、删除、定义与回滚脚本、独立版本历史，以及开发/测试/生产环境发布和验证记录。
- 多模板报告：支持周工作总结、项目进展报告、模型运行简报和专项检查报告；可创建、编辑和删除自定义模板，并保留模板报告历史。
- 报告定稿与版本：周报和模板报告支持草稿/定稿状态，每次保存生成版本快照；模板支持封面配置与自定义模板导入导出。
- 统一检索：键盘上下选择、Enter 打开；最近搜索与可命名保存的检索条件。
- 数据管理：备份保留策略、导入差异明细预览、整库恢复与按表恢复；导入和恢复前自动生成安全备份。
- AI 配置：兼容 OpenAI Chat Completions；密钥本地加密保存；未配置时智能整理回退本地规则。
- 访问密码：可选单用户访问保护（Cookie / Header）。
- 钉钉 / ICS 日程：只读订阅同步到「今日日程」；推荐使用钉钉日历导出的 ICS 链接。
- 本周计划：本周 / 下周 / 以后 / 已完成视图；任务支持等待对象。
- 本地持久化：FastAPI + SQLite；数据库采用增量迁移，升级时保留已有数据。浏览器离线打开时自动降级到演示模式和 `localStorage`。
- Docker：提供 `Dockerfile` 与 `docker-compose.yml`，数据目录可挂载。
- P1：任务重复与完成结果/耗时、数据请求组合筛选、记录收藏/归档/修订历史、统计复盘下钻、项目模板、定时备份、SQL 复制带参数清单。
- 首页卡片可拖拽重排并持久化；工作记录支持 Markdown 工具栏与预览；今日页数据请求改为真实数据。
- 响应式：桌面端为主要使用场景，窄屏提供折叠菜单和纵向布局。
- Apple HIG UI：正式工作台已完成侧栏、工具栏、内容层级、列表、详情抽屉、编辑器、弹窗、深色模式及移动端布局迁移。
- 所有内容均为虚构示例；当前版本不会连接或执行真实数据库 SQL。

## 首次安装

在 PowerShell 中进入本目录并运行：

```powershell
.\setup.ps1
```

## 启动

```powershell
.\run.ps1
```

然后访问：

```text
http://127.0.0.1:8765/
```

API 文档位于 `http://127.0.0.1:8765/docs`。

## Docker

```powershell
$env:WORKBENCH_SECRET = "请替换为随机密钥"
docker compose up -d --build
```

- 默认端口：`8765`
- 数据卷：`workbench-data` → 容器内 `/data`（对应 `WORKBENCH_DATA_DIR`）
- 可选环境变量：`WORKBENCH_SECRET`（加密密钥）、`WORKBENCH_PORT`

## 文件

- `index.html`：页面结构与示例业务内容。
- `styles.css`：原有基础样式与组件兼容层。
- `ui-apple-hig.css`：正式界面的 Apple HIG 设计系统与响应式迁移层。
- `APPLE-HIG-DESIGN-SPEC.md`：界面原则、令牌、组件和页面验收规范。
- `app.js`：交互逻辑与本地持久化。
- `backend/main.py`：FastAPI 入口（组装中间件与路由）。
- `backend/common.py`：共享查询、鉴权、设置与备份辅助。
- `backend/routers/`：按域拆分的 API 路由（tasks / reports / sql / data 等）。
- `backend/db.py`：SQLite 表结构、连接管理和示例数据。
- `backend/schemas.py`：API 请求模型。
- `backend/ai_client.py`：OpenAI 兼容聊天客户端。
- `backend/calendar_sync.py`：ICS 日程解析与同步。
- `backend/secrets_util.py`：本地密钥派生与密文加密。
- `backend/report_exports.py`：报告 Markdown、Word 与 PDF 版式生成（含可选封面页）。
- `Dockerfile` / `docker-compose.yml`：容器部署。
- `data/workbench.db`：本地数据库，首次启动自动创建。
- `data-model.json`：实体草案参考。
- `tests/test_api.py`：核心 API 自动化测试。
- `tests/test_smoke_flow.py`：解锁→任务→SQL 冒烟与访问加固测试。

## v1.9.0

- 后端路由拆分：`main.py` 仅组装 app；域路由位于 `backend/routers/`。
- 访问加固：连续失败锁定、改密使旧会话失效、会话到期提示；健康检查与设置页提示 `WORKBENCH_SECRET` 与最近备份。
- 催办：今日焦点标注逾期/提醒日/临近截止；催办条可「去处理 / 推迟 / 标完成」；可选桌面通知；`/api/reminders`。
- 周报：一键润色（不重新拉数）；生成/润色与 SQL 智能整理前确认 AI 发送范围。
- 冒烟测试覆盖关键读写路径。

## v1.7.0（P1）

- 任务：完成结果、实际耗时、重复（每周/每月/自定义）与提醒日；完成后自动生成下一次任务。

## v1.6.0

- AI：`/api/settings` 配置 base_url / model / api_key；智能整理、SQL 说明、周报生成优先调用真实模型，失败或未配置时回退本地规则。
- Docker：镜像 + compose + 数据卷；`WORKBENCH_DATA_DIR` / `WORKBENCH_SECRET`。

## v1.5.0 产品可用收尾

- `/api/settings`：备份保留数量（默认 20，范围 3–200）；创建手动备份后自动清理超限旧备份。
- `/api/backups/{name}` DELETE：删除指定备份；`/api/backups/{name}/restore-tables`：按表恢复。
- `/api/data/import/preview`：返回新增/更新/不变差异明细与示例 ID。
- `/api/recent-searches`、`/api/saved-searches`：最近搜索与保存的检索条件。
- 周报与模板报告支持定稿接口与 `report_versions` 版本历史。
- 报告模板支持封面配置，以及自定义模板 JSON 导入导出。

## v1.4.0 报告生产与检索闭环

- 自定义报告模板支持新建、编辑和删除，内置模板保持只读。
- 周报和模板报告均支持 Markdown、Word、PDF 输出。
- 统一检索覆盖存储过程和模板报告。

## 建议的下一阶段（非本版本范围）

1. 数据量和交互复杂度增长后，再评估使用 Vue 3 + TypeScript 组件化重构。
2. SQL 与存储过程执行功能需要单独设计权限、脱敏、审计日志和只读连接；当前版本明确不执行数据库代码。
3. 钉钉开放平台 OpenAPI 直连（当前以 ICS 导出为主）。
4. 多用户协作与权限（当前明确为个人单用户）。
5. 更完整的 WYSIWYG 富文本（当前为安全的 Markdown 子集）。
