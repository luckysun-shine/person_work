# 产品事实

- 产品名：数智审监工作台（Person Works）；本地单用户、自托管网页应用。
- 正式应用路径：`audit-ai-workbench-ui/workbench-v2`；当前版本 v1.9.29。
- 交付形态：同一 Web 应用；电脑浏览器完整操作，手机浏览器查看与轻量操作；可 Docker 部署后经局域网访问。
- 核心对象：任务、日程事件、数据请求、SQL 资产、监测模型、存储过程、审监监测台账、工作记录、导航项、周复盘/周报。
- 工作闭环：`工作请求 → 周计划/日程 → SQL 取数 → 模型维护 → 审监监测台账 → 记录复盘 → 周报输出`。
- 界面主题：Soft Welcome（暖黄浅底、顶栏胶囊导航、大圆角卡片）；方向选定见 `direction-approved.md`。
- 本周计划：展示周一至周日全部待办/计划与订阅日程；支持一键完成与日历同步。
- 审监监测台账：四大类（员工 / 经销商 / 合作商 / AI 助力）共 22 项预置；详情维护周期、规划逻辑、代码备份、更新步骤、执行记录。
- 数据请求可保存本次取数 SQL 文本，并可选关联 SQL 资产库条目。
- 日程：钉钉 CalDAV（推荐）或 ICS，只读同步；密码本地加密。
- 数据安全：SQLite 本地库、备份保留、导入差异预览、按表恢复；不连接、不执行真实业务库 SQL。
- 主视口以桌面为主（约 1440×900），窄屏有折叠导航降级。
- 示例数据均为虚构，勿放入真实审计明细、库地址、人员隐私或生产凭据。
