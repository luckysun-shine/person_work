# 审计 AI 个人工作台 · 统一设计方案 V2

## 产品定位

这不是通用待办工具，也不是数据大屏，而是审计监察数据分析师的个人工作操作系统。它负责把工作安排、临时取数、SQL 资产、监测模型、项目报告和过程记录串成一条可追溯的工作链。

## 核心工作闭环

1. 收到工作或数据请求，进入收件箱。
2. 将请求排入本周计划，明确交付时间与优先级。
3. 通过已有 SQL 或新建查询完成取数，并保存口径、参数和版本。
4. SQL 可以继续沉淀为监测模型或存储过程，并记录发布、验证和回滚步骤。
5. 结果进入项目、看板或报告，形成阶段成果。
6. 关键判断与复盘进入工作记录，后续可搜索和复用。

## 一级信息架构

- 今日：需要立即处理的任务、请求和异常。
- 本周计划：本周与下周的任务编排。
- 数据请求：部门内部取数需求及交付状态。
- SQL 资产：查询逻辑、参数、版本和复用记录。
- 监测模型：模型状态、运行结果、依赖和更新清单。
- 项目与报告：模型、看板、报告和知识库项目。
- 工作记录：决策、口径、问题、复盘与随手记。
- 常用导航：内部网站、数据库、BI、法规和知识库入口。

## 统一视觉原则

- 默认使用浅色专业界面，适合全天工作；代码区使用局部深色，而不是整站深色。
- 左侧栏提供稳定定位，顶部用于全局搜索和快速创建。
- 首页不堆装饰性指标卡，只显示会改变下一步行动的信息。
- 采用一套状态颜色：蓝色表示进行中，绿色表示完成，橙色表示等待，红色表示风险。
- 用表格承载资产，用时间线承载进展，用抽屉承载详情，减少频繁跳页。
- 所有列表都围绕“名称、归属、状态、更新时间、下一步”组织。

## 本轮原型范围

单文件 HTML 原型，包含今日、本周计划、数据请求、SQL 资产、监测模型、项目与报告、工作记录和常用导航八个工作区。支持导航切换、全局检索、任务勾选、周视图切换、列表筛选、SQL 详情抽屉、模型更新步骤和快速记录。
