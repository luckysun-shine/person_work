采购付款异常明细

识别同一供应商短周期拆分付款、单笔超阈值以及审批后异常加速付款。

42累计复用
正式用途说明
采购异常监测模型的明细取数层；结果进入人工复核，不直接形成审计结论。

查询正文

-- 参数：:start_date, :end_date, :amount_limit
WITH payment_window AS (
  SELECT
    p.vendor_id,
    v.vendor_name,
    p.payment_date,
    p.amount,
    SUM(p.amount) OVER (
      PARTITION BY p.vendor_id
      ORDER BY p.payment_date
      RANGE BETWEEN INTERVAL '7' DAY PRECEDING
      AND CURRENT ROW
    ) AS amount_7d
  FROM fct_payment p
  JOIN dim_vendor v ON p.vendor_id = v.vendor_id
  WHERE p.payment_date BETWEEN :start_date AND :end_date
)
SELECT *
FROM payment_window
WHERE amount_7d > :amount_limit
ORDER BY amount_7d DESC;
AI 逻辑摘要 · 非正式字段在七天滚动窗口内按供应商累计付款金额，并筛出超过参数阈值的记录。使用前仍需核对冲销、预付款及币种换算口径。
